## 已知限制

- 网页不会自动抓取 Amazon，也不能从普通 Excel 内嵌图片稳定提取原图；推荐导入公开图片 URL、带超链接的图片单元格或卖家精灵可识别的图片字段。
- 缺图记录可以正常进入产品库和数据待补，但商品卡会显示图片占位，补齐真实主图链接后才会恢复完整卡片。
- 利润预测只是低权重参考，立项前仍需真实报价、包装方案和头尾程核算。
- Sites 地址可能被部分公司网络拦截；公司电脑仍应保留 GitHub Release 的 Chrome 单文件版作为备用。
