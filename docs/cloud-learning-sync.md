# LINX 云端工作区同步

LINX 的产品记录和人工决策以云端工作区为跨设备真相。本机存储只承担离线缓冲和故障恢复，不能作为跨电脑的最终状态。

## 同步范围

- A/B/C/D 单款与批量定级
- 收藏与取消收藏
- 回收站移入与恢复
- 未分类产品的手动大类目
- 偏好校准、学习事件、复盘报告与偏好规则启停
- 产品新增、编辑、CSV/XLSX 导入和 JSON 备份恢复

## 运行方式

1. 页面打开时读取完整云端档案，再与本机尚未上传的操作按 ASIN 和操作时间合并。
2. 本机新增操作只生成差异补丁；学习操作和产品记录都会拆分为小于请求上限的批次，不再上传整个档案。
3. 服务端把定级、收藏、回收、分类和学习事件按类型与 ASIN/事件 ID 分行保存；旧版整包档案只作为只读基线，不再把不断变大的完整 JSON 写回单个数据库字段。
4. 打开的页面每 5 秒读取一次轻量修订号；发现其他电脑有新操作时才拉取完整档案。窗口重新获得焦点时也会立即检查。
5. 网络失败时操作继续保存在本机，页面明确显示待同步数量；网络恢复或下次打开时自动补传。

服务端的分行记录按操作时间做幂等更新。两台电脑同时操作不同产品时各自保存；同一产品发生冲突时保留时间更新的人工操作。修订号只用于通知其他设备重新拉取，不承担整包覆盖写入。

## 历史本机档案恢复

旧版本曾整包上传学习档案，超过 5 MB 时会失败。新版本会将仍保存在浏览器里的历史操作按差异拆分补传。恢复前不要清除浏览器缓存、站点数据或 LINX 的本机存储；看到“云端同步完成”后再在另一台电脑核对数量。

2026-08-04 起，云端学习档案不再受单个 SQLite 字段大小限制。旧云端档案保留不动，新补传的记录追加到分行增量层，读取时合并为同一份学习档案。

Chrome 单文件版没有 Sites 云端接口，只能保留本机状态和 JSON 备份。需要跨设备实时同步时使用已发布的 LINX Sites 地址。
