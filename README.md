# LINX

面向 Amazon 美国站家具产品开发的本地选品工具。支持直接导入卖家精灵 CSV/XLSX，结合市场、包装物流、利润预测、公司供应链与个人开发偏好，自动筛选值得跟进的产品机会。

## 主要能力

- 自动读取卖家精灵的 ASIN、类目、价格、销量、上架天数、增长率、评分、包装重量与尺寸。
- 自动排除玻璃、纯金属标准品、超围长、低售价和不符合公司方向的产品。
- 根据 22 kg、49 kg、50 lb、包装尺寸和围长节点评估物流风险。
- 结合历史利润表自动预测利润，不要求逐条人工核算。
- 识别功能结构、场景工作台、收纳系统、波纹/卷帘等开发方向。
- 输出优先跟进、有条件跟进、需要优化、暂不建议和待核算结论。

## 公司电脑首次使用

1. 安装 [Node.js](https://nodejs.org/) 22.13 或更新版本。
2. 安装 [Git](https://git-scm.com/download/win)。
3. 克隆本仓库并进入项目目录。
4. 在项目目录打开 PowerShell，执行：

   ```powershell
   npm install
   npm run dev
   ```

5. 浏览器打开终端显示的本地地址，通常为 `http://localhost:3000`。

## 日常使用

在“数据管理”中导入卖家精灵导出的 CSV/XLSX，然后进入“机会筛选”。工具默认只展示“优先跟进”和“有条件跟进”的产品，全部原始记录仍保留在数据管理中。

数据保存在当前浏览器本地。更换电脑前请在“评分设置”中下载 JSON 备份，再在新电脑恢复。
