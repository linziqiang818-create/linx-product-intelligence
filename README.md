# LINX 选品工作台

面向 Amazon 美国站家具产品开发的本地选品工具。把卖家精灵初筛后的表格导入，按公司硬性条件自动分流，再由“第二大脑”按你的偏好排序。

## 三个空间

| 空间 | 内容 | 你能做什么 |
| --- | --- | --- |
| ① 产品库 | 所有导入过的产品，按 ASIN 去重 | 导入卖家精灵表格、筛选、导出 |
| ② 适配池 | 通过公司硬性条件的产品；「已清除」折叠区按原因分组（类目不做 / 普货不做 / 材质不做 / 材质可改款 / 手动清除） | 看到不该在的就「移出」，看到能改款的就「捞回」 |
| ③ 第二大脑 | 适配池里最可能是你想开发的产品，按偏好排序并附理由 | 👍 👎 直接纠正排序 |

收藏夹独立成页；收藏、捞回、移出、👍 👎 都会成为第二大脑的偏好信号（约 4 个月衰减一半）。

## 发现箱（自动采集）

顶栏「发现箱」存放自动抓来的 Amazon 新品候选：每天按你配置的关键词抓搜索页，本地粗筛（价格带 + 明显不做的品类）后抓详情页，新产品进箱等你过目——**收进来**就按硬性规则归位、进入三层池；**不要**则永久静默，同 ASIN 不再进来。服务运行时每 6 小时检查一次，距上次采集超过 22 小时自动跑一轮；也可手动点「立即采集」。

额度闸门双保险：每天搜索/详情请求数上限在「采集设置」里改（默认 10 + 30 次，免费额度 5,000/月用不完），Bright Data 免费档用完自动硬停、不产生账单。抓取走 [Bright Data](https://brightdata.com)（自动换 IP/解验证码），本机 `bdata login` 授权一次即可，或设 `BRIGHTDATA_API_KEY`。注意：免费号请求打太密会触发限流，采集器已内置 4 秒间隔 + 限流自动等待重试。

## 日常使用

双击桌面快捷方式「LINX 选品工作台」（或项目目录里的 `启动 LINX.cmd`）。脚本会自动：检查 Node.js → 首次安装依赖 → 首次构建界面 → 启动数据服务 → 打开 `http://localhost:3000`。关闭黑色窗口即停止服务。

首次打开时若浏览器里还留有旧版数据（localStorage），页面顶部会提示一键导入，收藏和历史校准会一并转成偏好信号。

## 访问密码

双击启动时服务默认开启 HTTP Basic 访问密码（账号 `linx`，密码在 `scripts/launch-linx.ps1` 顶部的 `LINX_PASS` 一行，直接改即可）。浏览器输入一次就会记住，之后照常使用。这是给内网穿透、公网访问兜底的保护。直接 `npm start` 且未设置环境变量 `LINX_PASS` 时不启用密码（开发场景）。

## 规则怎么改

设置 → 硬性规则。每条规则都是关键词（正则），开关即时生效，保存后所有产品重新归位。右侧「规则试算」可以贴一个标题看会被怎么判；「每条规则清了多少 · 被你捞回多少」用来发现太严的规则。

默认边界（可改）：

- 材质：做板材 + 亚克力；玻璃 / 镜面清除但标「玻璃 → 亚克力」；纯金属主体清除但标「金属 → 板式」，板材 + 金属配件可以做；含软包清除，鞋凳 / Hall Tree 的单块坐垫例外；纯实木清除。
- 类目：婴儿、户外、浴室柜、灯具、吊顶储物架不做。
- 座椅：椅子类目和带座椅的套装不做，但不只看标题——先去掉「for 6 chairs」「chair rack」这类反证，只认「with 3 Stools」这种明确包含的写法，单把椅子还要类目确认；推车 / 玄关 / 鞋柜 / 缝纫收纳等安全类目一律不清。
- 普货：床架、书架、鞋柜、普通电动升降桌、简易茶几边几、简易电视柜、普通固定书桌、简易餐边柜——仅当标题没有任何造型 / 功能 / 场景差异化关键词时才算普货。
- 只标记不清除：非常规材质（岩板 / 竹 / 藤 / 树脂 / 水泥）扣分，包装毛重 > 50 kg 标高运费，缺包装数据标数据待补，含壁炉标「壁炉 → 留位或改储物」。

## 数据在哪

`data/linx.db`（SQLite，单文件）。不再依赖浏览器缓存。设置 → 数据 可下载完整备份 / 恢复备份；换电脑或给同事用，把备份恢复进去即可。将来部署到服务器加登录，架构不用改。

## 开发

```bash
npm install          # 安装依赖
npm run build        # 构建前端到 dist/
npm start            # 启动服务（端口 3000，托管 dist/ 与 /api）
npm run dev          # 前端热更新（5173，/api 代理到 3000）
npm test             # 规则引擎 / 偏好引擎 / 数据层 / 导入器测试
npm run scan         # 缺口扫描（只读）：缺翻译 / 缺包装数据 / 跟进名单 / 数据新鲜度
npm run typecheck    # TypeScript 检查
npm run shortcut     # 重新创建桌面快捷方式
```

目录：

- `server/` 数据服务：`rules-config.mjs` 默认规则、`rules.mjs` 归位引擎、`assess.mjs` 需求与利润模型、`preference.mjs` 第二大脑、`db.mjs` SQLite 数据层、`importer.mjs` 表格导入导出、`api.mjs` 接口、`data/seed/` 初始数据。
- `src/` React 前端：`pages/SpacePage.tsx` 三空间与收藏夹、`pages/SettingsPage.tsx` 设置、`components/` 卡片 / 筛选栏 / 详情抽屉等。
- `docs/选品逻辑.md` 选品的底层共识（好素材的两大类、界面呈现约束、第二大脑收敛原则）——改评分、改规则、改界面之前先读一遍。
- 环境变量：`LINX_PORT`（默认 3000）、`LINX_DB`（默认 `data/linx.db`）、`LINX_HOST`（默认 `0.0.0.0`，同一局域网的同事可通过你的 IP 访问）、`LINX_USER` / `LINX_PASS`（设置后启用访问密码，启动脚本默认已设置）。
