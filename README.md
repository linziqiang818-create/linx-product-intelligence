# LINX

LINX 是面向 Amazon 美国站家具产品开发的本地选品工作台。它把卖家精灵或人工整理的数据统一归位，帮助判断“是否适合公司开发、属于哪条机会线、还缺什么证据”，而不是把销量或预测利润当成唯一结论。

## 当前能做什么

- 导入卖家精灵 CSV/XLSX 或通用模板，先预览再确认；按 ASIN 累计新增或非空更新。
- 用同一套规则处理历史产品、每日新增、手工导入和候选深挖结果。
- 将产品分为 A/B/C/D；D 只进入垃圾箱，非 D 只进入一条主归位：红海中的蓝海、蓝海中的红海或方向不匹配。
- 将潜力款、数据待补和收藏作为可重叠标签，不用缺失数据代替淘汰判断。
- 支持批量选择、收藏、对比、候选 ASIN 导出和两阶段校准。
- 在线版会跨电脑同步产品修改、人工分类、收藏和校准反馈；本机仍保留待同步副本并支持 JSON 备份/恢复。

页面显示的正式池数量是动态结果。每日最多 300 款只是冲刺期的正式入库上限，不代表每天一定新增 300 款，也不是任何页面或分类的容量限制。

## 最容易的使用方式

### 家里电脑：本地开发版

双击已有的“北极星选品”桌面快捷方式；或在项目目录运行：

```powershell
npm install
npm run dev
```

浏览器地址通常是 `http://localhost:3000`。运行期间不要关闭启动窗口。

### 公司电脑：Chrome 单文件版

从本仓库的 [GitHub Releases](https://github.com/linziqiang818-create/linx-product-intelligence/releases) 下载最新的 `LINX-Open-in-Chrome-*.html` 或 Chrome 一键包，用 Google Chrome 打开。正确打开时地址栏以 `file:///` 开头，不需要安装 Node.js，也不需要保持黑色窗口。

公司网络曾拦截 `chatgpt.site`，因此它不是公司电脑的可靠入口。单文件版是已经在公司 Chrome 实际验证过的方式。

## 日常选品流程

1. 在“产品库”上传卖家精灵 CSV/XLSX，先核对新增、更新、重复、缺图和错误行，再确认导入。
2. 在“机会筛选”查看两条机会线；在“方向不匹配”“潜力款”“数据待补”继续分层研究。
3. 收藏或勾选产品，进入并排对比；确定需要深挖的产品后导出候选 ASIN。
4. 在“校准模式”持续记录兴趣和拒绝原因。只有明确的类目级禁做反馈才能形成硬规则。
5. 在线版会自动同步人工操作；重要批次仍建议在“分类标准与数据”下载 JSON 备份留档。

导入不会清空历史产品。旧 ASIN 只用 Excel 中非空的字段更新，空单元格保留旧资料；缺图产品正常进入产品库并显示为“待补数据”，不会暂停整批。

候选池中的轻量发现不会自动出现在机会筛选。产品必须先完成基本真实性和字段验证，才会进入正式池。

## 验证命令

```powershell
npm run lint
npm test
git diff --check
```

`npm test` 已包含普通构建、Chrome 单文件构建和全部回归测试。仅生成单文件版可运行：

```powershell
npm run build:portable
```

输出位于 `.run/LINX.html`。
