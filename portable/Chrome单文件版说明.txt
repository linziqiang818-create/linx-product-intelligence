LINX 公司电脑 Chrome 单文件版

推荐操作：
1. 将 ZIP 压缩包完整解压到普通文件夹。
2. 双击“打开LINX-谷歌浏览器.cmd”。
3. 程序会直接使用 Google Chrome 打开同目录的 LINX.html。

也可以直接右键 LINX.html，选择“打开方式”→“Google Chrome”。

正确打开后，Chrome 地址栏以 file:/// 开头，不是 chatgpt.site。
本版本不需要安装 Node，不启动本地服务器，也不需要保留黑色窗口。

数据说明：
- 产品数据包含在 LINX.html 内，必须通过私有 GitHub 下载。
- 收藏、校准反馈和手工修改保存在当前公司电脑的浏览器中。
- 更换电脑前，请在 LINX 中下载 JSON 备份。
